# Third-party code and data

SecondOpinion uses the open-source libraries below. Versions are the ones locked or installed
for the hackathon build. Licenses were read from each package's own metadata.

modify:

  dynamically linked, unmodified.

- `caniuse-lite` (CC-BY-4.0): browser support data used at build time.

## Data

No data files are committed. The audit reads the frozen TCGA-BRCA release that each user fetches
with the organizers' `fetch.py`. See [docs/challenge/DATA_LICENSES.md](docs/challenge/DATA_LICENSES.md).

- TCGA: "The results shown here are in whole or part based upon data generated by the TCGA
  Research Network: https://www.cancer.gov/tcga."
- UCSC Xena: Goldman, M.J. et al. Visualizing and interpreting cancer genomics data via the Xena
  platform. *Nat Biotechnol* 38, 675–678 (2020).
- Survival data: Liu, J. et al. An Integrated TCGA Pan-Cancer Clinical Data Resource to Drive
  High-Quality Survival Outcome Analytics. *Cell* 173, 400–416 (2018).
- NCI Imaging Data Commons: Fedorov, A. et al. *RadioGraphics* 43 (2023).

The challenge specification, findings schema and `validate.py` under `docs/challenge/` are a
snapshot from the organizers' repository; see [docs/challenge/SOURCE.md](docs/challenge/SOURCE.md).
