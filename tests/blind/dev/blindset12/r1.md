# Year 2 Progress Report, Aim 1: Assembling a multi-layer breast cancer cohort

**Grant period:** second funding year. **Data:** TCGA-BRCA, release A.

## Summary of progress

This report summarizes work on Aim 1 during the second funding year. Our goal for the year was to build a fully reconciled sample table across every data layer.

## Milestone 1.1: Data intake

We have assembled the full set of 1,236 survival records, of which 132 come from normal tissue samples. The RNA file contains 1,218 samples, including 114 normal tissue samples. None of the 139 normal tissue samples has mutation or copy-number data. All seven metastatic samples have RNA data, and six of them also have protein data.

## Milestone 1.2: Layer reconciliation

The protein file profiles 131 antibodies. Copy-number calls span more than 25,000 genes. This milestone is now complete: primary tumors with both copy number and protein data number 742. Every primary tumor in the release has a clinical record.

## Milestone 1.3: Pathology linkage

Only three primary tumors lack any pathology slide in the manifest. Re-consent was obtained from all living participants for the extended slide analyses.

## Plans for Year 3

Aim 2 work will begin next quarter. We request no change to the approved budget.
