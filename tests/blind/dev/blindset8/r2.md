# Research brief: How the data layers overlap in TCGA breast cancer

*A short fictional research summary written by the organizers for testing. It describes the TCGA-BRCA files in this repository (release A from `fetch.py`).*

Multi-omic studies depend on having several measurements from the same tumor. Mutation calls are available for 791 primary tumors, far fewer than the 1,080 with copy number data. Mutation and copy number data overlap in 785 primary tumors.

Almost every primary tumor has RNA data, with only four missing. Protein data covers 742 primary tumors, about 67% of all primaries. Of the 791 tumors with mutation calls, 547 also have protein data. Tumors were chosen for protein profiling because they had higher tumor purity.

Sample types matter here as well. Survival is recorded for 1,097 primary tumors and for all 139 normal tissue samples. The protein file also holds 5 metastatic samples, and the RNA file holds 114 normal tissue samples.

We recommend that cohorts be defined by the layers each question actually needs.
